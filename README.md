# موقع "حضن" — رسالة حب حقيقية

## هيكل المشروع (Folder Structure)

```
love-website/
│
├── index.html          # الصفحة الرئيسية (قفل PIN + الموقع كامل)
├── style.css           # كل التصميم (Glassmorphism, ألوان, حركات)
├── script.js           # كل المنطق: القفل, GSAP, Three.js, العداد, التأثيرات
│
└── assets/
    ├── music/
    │   └── piano-theme.mp3     ← ضيفي هنا ملف البيانو (mp3)
    ├── images/
    │   ├── memory1.jpg  ← الصورة الأولى
    │   ├── memory2.jpg  ← الصورة التانية
    │   ├── memory3.jpg  ← الصورة التالتة
    │   ├── memory4.jpg  ← الصورة الرابعة
    │   └── memory5.jpg  ← الصورة الخامسة
    ├── animations/       ← لو عايز تضيف Lottie JSON files هنا
    └── fonts/            ← لو عايزة خط مخصص (اختياري, دلوقتي بيستخدم Google Fonts: Cairo)
```

## إضافة موسيقى الخلفية (Background Music)

1. اختاري ملف بيانو هادي بصيغة **MP3** (حجم مناسب, يفضل أقل من 5MB عشان التحميل يكون سريع).
2. سميه بالاسم: `piano-theme.mp3`
3. ضعيه في المجلد: `assets/music/piano-theme.mp3` (استبدلي ملف الـ placeholder الموجود).
4. الموقع مبرمج بالفعل عشان:
   - يشغل الموسيقى تلقائيًا لما يفتح الموقع (لو المتصفح يسمح بالـ autoplay).
   - فيه زرار تشغيل/إيقاف (🎵) تحت يسار الشاشة.
   - فيه Slider للتحكم في الصوت.
   - الصوت بيهدى لوحده تلقائيًا في اللحظات الهادية (quiet moments) في الصفحة.

> ملاحظة: أغلب المتصفحات (Chrome/Safari) بتمنع الـ autoplay بصوت لحد ما المستخدم يتفاعل مع الصفحة (زي الضغط على PIN). بما إن الموقع فيه شاشة قفل بالـ PIN, أول ضغطة على الأرقام هتفعّل إمكانية تشغيل الصوت تلقائيًا بعد الفتح.

## استبدال الصور

استبدلي الملفات دي بصور حقيقية بنفس الاسم:
- `assets/images/memory1.jpg` إلى `memory5.jpg`

يفضل تكون الصور بنسبة أبعاد قريبة من 4:5 (portrait) للحصول على أفضل شكل في الجاليري.

## الـ PIN

الرقم السري هو **2211** (مبرمج جوه script.js, غير ظاهر في الصفحة).

## تشغيل الموقع

الموقع static بالكامل — تقدر تفتحيه مباشرة بفتح `index.html` في المتصفح, أو ترفعيه على أي استضافة static زي GitHub Pages / Netlify / Vercel.

⚠️ لو حابب Autoplay صوت يعمل 100% من أول ما الصفحة تفتح بدون أي تفاعل, غالبية المتصفحات مش هتسمح — الحل المطبق هنا (تشغيل الصوت بعد إدخال PIN) هو أفضل حل عملي ومتوافق مع كل المتصفحات.
